# Support

For usage questions, search existing GitHub issues and then open a redacted bug
report or discussion. Include the package version, Python version, operating
system, `pass --version`, the command with private paths replaced, and a minimal
synthetic entry shape.

Do not post real credentials, `.gpg` files, private keys, passphrases, TOTP seeds,
CSV exports, or unredacted logs. Security vulnerabilities must use the private
reporting link in [SECURITY.md](SECURITY.md).

This is a volunteer-maintained project. Response times and compatibility with
future Proton Pass import changes are not guaranteed.
